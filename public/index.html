Welcome to Ollama Proxy

A production-ready proxy server for Ollama with built-in management interface

Interactive Chat

Chat with any downloaded Ollama model directly from the web interface. Supports real-time streaming responses.

Model Management

Download new models from the Ollama library or remove existing ones. Monitor download progress in real-time.

API Token Management

Create and manage API tokens for secure access to the proxy endpoint. Perfect for integrating with other applications.

Secure Access

Password-protected web interface with session management. API endpoints secured with Bearer token authentication.

OpenAI Compatible

API endpoint compatible with OpenAI's chat completions format. Easy drop-in replacement for existing applications.

Docker Ready

Fully containerized with Docker support. Easy deployment with docker-compose and persistent volume storage.

API Documentation
v1

Use the API endpoint to integrate Ollama with your applications.

Endpoint: POST /v1/chat/completions

curl -X POST http://your-server:924/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -d '{
    "model": "llama3.2",
    "messages": [
      {"role": "user", "content": "Hello!"}
    ],
    "stream": false
  }'
